# 形式化过程中对论文的修正 / 补充假设

记录所有「Lean 里的陈述 ≠ 论文字面陈述」的地方。每条给出：论文位置、问题、
形式化里怎么处理、以及是否影响主定理。

| # | 论文位置 | 问题 | 处理 | 影响 |

| 1 | §2.1 / §8，`S^(B)_{ab} = (1/5)·1(\|a-b\|_L ≤ 1)` | 原稿写「Fix positive integers `W, L > 0`」，未要求 `L ≥ 3`。`L = 1, 2` 时五个格点 `(0,0), (±1,0), (0,±1)` 不互异，行和分别是 `1/5`、`3/5`，故「`S` 是随机矩阵」这句按字面是假的 | **已改论文**：`L ≥ 3` 写进模型定义那一句，并在紧接的 Note 与 Notations 里各记一笔为什么无损（结论都是 `L → ∞` 的渐近）。Lean 侧 `3 ≤ L` 仍是显式假设 | 无。已不再是偏差 |
