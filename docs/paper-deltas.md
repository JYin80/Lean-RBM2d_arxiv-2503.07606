# 形式化过程中对论文的修正 / 补充假设

记录所有「Lean 里的陈述 ≠ 论文字面陈述」的地方。每条给出：论文位置、问题、
形式化里怎么处理、以及是否影响主定理。

| # | 论文位置 | 问题 | 处理 | 影响 |
|---|---|---|---|---|
| 1 | §2.1 / §8，`S^(B)_{ab} = (1/5)·1(\|a-b\|_L ≤ 1)` | 论文未显式要求 `L ≥ 3`。`L = 1, 2` 时五个格点 `(0,0), (±1,0), (0,±1)` 不互异，行和 ≠ 1，随机性失效 | Lean 中把 `3 ≤ L` 作为显式假设写进所有涉及随机性的引理（`card_sbSupport`、`sum_SB_row` 等） | 无。论文关心 `L → ∞` |
| 2 | §8 开头，`\|x\|_L` | 论文用周期**欧氏**范数 `min_{n∈Z²}\|x+nL\|`，并明说周期 L¹ 与 L² 相差至多 `√2`、而 `lem_propTH` 的估计都是「指数里差常数、外面差 `≺`」，故两者可互换 | Lean 里 `RBM.zdist2 = zdist(x₁) + zdist(x₂)`，即周期 **L¹**。这是论文授权的替换 | 无。`√2` 被吸收进指数里的常数 `c` |
| 3 | Def `stoch_domination` (ii) vs §8 开头 | 定义 (ii) 写的是 `ξ ≤ N^τ ζ`；§8 开头重述 `≺` 时写的是 `A ≤ C_ε L^ε B`。两者尺度不同 | Lean 的 `RBM.DetDom` 序列参数取 **`L`**（§8 的版本）。因 `L ≤ N`，`L`-版本更强、蕴含定义 (ii) | 无，方向有利 |
| 4 | Def `stoch_domination` (ii) | 论文只对「非负确定量」陈述，且 (i) 是「uniformly in `u ∈ U(N)`」，而 `(prop:BD1)(prop:BD2)` 对格点一致成立 | `RBM.UnifDetDom` 带参数族、`L₀` 与 `u` 无关；`RBM.DetDom` 是单点特例。定义里**不要求非负**，需要非负的引理显式带假设 | 无 |
| 5 | `(eq_elliptic)` 的证明，`λ ≤ 1/2` 分支 | 论文写「`\|1-λξ\| ≥ 1 - \|λ\|\|ξ\| ≥ 1/2`」。但这一支里 `λ ∈ [-3/5, 1/2]`，故 `\|λ\| ≤ 3/5`，`\|ξ\| → 1` 时下界只到 **2/5**，不到 1/2 | Lean 里这一支用 `2/5`；两支合并后统一取常数 `1/9`（论文在另一支给的是 `1/4`） | 无。论文只需要一个正常数，`1/2` 这个具体数字在后文没有被用到。**但提交版里这句话按字面是错的，值得改成 `2/5` 或直接写「≥ c」** |
| 6 | `def_Theta`，`Θ^(B)_ξ = (1 - ξ S^(B))^{-1}` | 论文把它当矩阵的逆；Lean 需要先说明可逆 | `RBM.Theta = Ring.inverse (1 - ξ • SB L)`，在 ℓ^∞ 算子范数下由 `‖S^(B)‖ = 1` 与 `‖ξ‖ < 1` 得单位性。性质 1–3 全部由**逆的唯一性**（`eq_Theta_of_mul`）从 `S^(B)` 的相应性质推出，不走 Neumann 级数逐项论证 | 无 |
| 7 | `(eq_elliptic)` 的 `∼` | 论文写 `\|1-ξŜ(p)\| ∼ κ² + q(p)`，`∼` 是「相差绝对常数的双边界」 | 拆成两条：`norm_one_sub_mul_Shat_le`（上界，常数 1）与 `norm_one_sub_mul_Shat_ge`（下界，常数 `1/9`）。常数不求最优 | 无 |
| 8 | Thm `MR:decol` 的证明 | 论文由局部半圆律 `MR:locSC` 以高概率给出 `G = O(1)` 再代入特征向量不等式 | 只形式化确定性部分：`sq_norm_eigenvector_le_im_green`，以及「若 `‖G_xx(λ_k+iη)‖ ≤ C` 则 `\|ψ_k(x)\|² ≤ Cη`」。`G` 的界作为假设。特征值按 Mathlib 的 `IsHermitian.eigenvalues` 编号（不保证论文的 `λ_1 ≤ … ≤ λ_N` 次序），陈述对每个 `k` 成立故无影响 | 概率部分待随机层 |

| 9 | `(eq_elliptic)` 的上界 | 论文把 `∼` 的两半都放在 `\|ξ\| < 1` 之下陈述 | Lean 里 `norm_one_sub_mul_real_le` / `norm_one_sub_mul_Shat_le` **不带任何关于 ξ 的假设**：上界 `\|1−λξ\| ≤ (1−λ) + \|1−ξ\|` 只是对 `1−λξ = (1−λ) + λ(1−ξ)` 用三角不等式，`\|λ\| ≤ 1` 就够。只有下界需要 `Re(1−ξ) > 0`，即需要 `\|ξ\| < 1` | 无，是加强 |

## 待记录（做到时补）

- `(deri_Thxi)` 在 Lean 里陈述成**逐元素**形式而非矩阵值 —— 原因是 Matrix 上 Pi 拓扑
  与范数拓扑的实例菱形；`RBM1D` 那边已踩过，T6 落地时把这一条补进上表。
- T2 里 `dist(2π p.val/L, 2πZ)` 被替换成 `2π·zdist(p)/L` —— 这是恒等式不是近似，
  但仍然值得记一条，因为它把论文的 `\|p\|_*` 换了一种写法。
