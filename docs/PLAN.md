# 形式化路线图（RBM2D）

## 项目形状（为什么是这个形状）

1. **§3–7 的 loop 估计可避开随机分析接口**。2026-09-20 的随机层审计
   （`docs/random-layer.md`）显示，这段论证只需要一时刻边缘律，不消费
   适应性、Markov 性或两时刻联合律。因此这一段走 **d=1 的替代栈**：
   `H_u := √u·X` 一时刻边缘律 + 高斯分部积分（Stein）
   + 生成元恒等式 + 保持 $\eta$ 尺度的积分—上确界—二次不等式收口
   + 连续归纳（替代停时）+ 两座 `≺`⇄矩 的桥。
   论文自己就在用这个表示（`7:431`、式 (30)）。**Bulk universality 的
   证明另用矩阵 Ornstein--Uhlenbeck 过程及外部 Dyson Brownian motion 定理，
   不在这一替代栈的结论内**；见阶段 10。
2. **目标是整篇论文的证明链**，先完成 §2.5 的传播子 `Θ^(B)_ξ` 与 **§8 全部**。
   §8 是本文相对 [YY_25] 必须重做的确定性核心；其后将 §3–7 的模型、
   随机估计和组合层逐项接入蓝图。未形式化的引用只作明确标注，不算完成。
3. **永不写 `axiom` 或 `sorry`。** 尚未证明的数学结论必须在蓝图与工单中
   标成未完成；允许诚实的条件引理作中间结果，但不能用可任意赋值的
   `structure` 证明字段或定理参数掩盖目标缺口。`RBM2D.lean` 末尾的
   `#assert_rbm_axioms` 对整个 `RBM` 命名空间硬检查，没有 allow-list。
4. **自下而上建确定性骨架，§8 是当前主战场；随机层并行走一时刻边缘律
   与 Stein 恒等式路线。**

### 为什么把阶段 2 排在阶段 3 前面

论文 §8.2 的两个区制难度天差地别：

- `κL ≥ 1`（`ℓ̂ = κ⁻¹`）：需要无穷体积核、Cauchy 定理做围道平移、Poisson 求和。
- `κL < 1`（`ℓ̂ = L`）：**只需要把零模单独拎出来**，其余模用椭圆性，
  再加一条 `Σ_{p ∈ T_L²\{0}} |p|_*^{-2} ≤ C L² log L`。三行纸、Lean 里大概一天。

§8.3 的 Case 2（`|s|_L > d/2`）同理，也只用椭圆性。
先把这两块做掉，`lem_propTH` 的性质 5、6 就各有一半是定理而不是猜想了，
而且 `Σ_{p≠0}|p|_*^{-2}` 这条格点求和引理在阶段 3、4 里还会反复用到。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 新工作树缺编译依赖或联网受限 | 先核对锁定版本；可从 d=1 本机缓存建立独立的 copy-on-write 副本，再以全量 `lake build` 验证 |
| Mathlib 版本 API 漂移 | 锁死 `v4.34.0`；不确定的名字先 grep 或 `#check` |
| `Prod` 上的 `Finset` 记账（五点支撑集的互异性） | 全部集中在 `Defs/Block.lean` 的 `card_sbSupport` / `sum_over_sbSupport` 两条，改一处即可 |
| 围道平移在 Lean 里成本失控 | 先做阶段 2（不需要围道）。**Combes–Thomas 已单独立为 T29**：它能独立结清性质 5 的两个 ξ（`|1−ξ| ≥ c`，正是 §3–§4 实际消费的区制），但衰减率退化到 `κ²`，`1/L ≤ κ ≪ 1` 仍然要围道，**不能替代 T27+T28** |
| 显式常数 C、c 的追踪很痛 | 统一 `∃ C > 0, ∃ c > 0, ∀ ...`，不求最优；`≺` 用 `DetDom` 封装 |
| Bulk universality 的外部随机分析 | §3–7 的替代栈不覆盖 §2 的短时 OU 比较；为 `Thm: B_Univ` 单列阶段、引用依赖和验收门槛 |
