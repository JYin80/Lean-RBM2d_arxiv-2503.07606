## 3. 枢纽那条「巧合」——在，逐字对得上

BDG 右端（式 **108**）：

```
E[ ∫_s^τ (U_{u,t,σ} ∘ E^{(M)}_{u,σ})_a ]^{2p}
  ≤ C · E( ∫_s^τ ((U_{u,t,σ} ⊗ U_{u,t,σ̄}) ∘ (E⊗E)_{u,σ})_{a,a} du )^p
```

鞅项定义（式 **36**）`E^{(M)}_{t,σ,a} = Σ_α (∂_α L_{t,σ,a})(S_α)^{1/2} d(B_t)_α`，
于是生成元恒等式作用在 `|F|^{2p}` 上的二阶项 `|F|^{2p−2}·Σ_α S_α|∂_α F|²` 满足

```
Σ_α S_α |∂_α F|² = ∫_s^t ((U ⊗ U) ∘ (E⊗E)_{u,σ})_{a,a} du
```

**逐字等于 (108) 的右端。** 计数也对上：`∂_{H(x,y)}` 把一条 `G` 边剪成 `G E_{xy} G`（对应式 106 的 `Σ_k`），
`S_{xy} = W^{-2}S^{(B)}_{[x][y]}`，`x`、`y` 各在一个块里有 `W²` 个格点，
`W⁴·W^{-2} = W²` 正是 (106) 的前因子。

**所以论文从 (125) 起对二次变差做的那一大段估计原封不动保留**，只是改由生成元产出。

> 必须计入预算的细节：论文**从未显式写出** `Σ_α S_α ∂_αL·conj(∂_αL) = (E⊗E)`，
> Def 5.4 是组合式描述。Lean 里这条恒等式要**证出来**（纯有限代数：预解式求导 + 分块求和重排）。
